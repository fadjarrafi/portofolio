Debouncing adalah teknik untuk menunda sebuah fungsi sampai rentetan aktivitas mereda. Trik kecil ini membuat aplikasi terasa lebih mulus sekaligus memangkas banyak pekerjaan yang sia-sia.

## Apa itu debouncing

Idenya sederhana: alih-alih menjalankan fungsi di setiap event, kita menunggu sampai event-nya berhenti selama jangka waktu tertentu, lalu menjalankannya sekali.

Mengetik di kotak pencarian adalah contoh klasiknya. Kita tidak mau mengirim request di setiap ketikan — itu bikin UI terasa laggy dan membebani API. Sebagai gantinya, kita menunggu sampai user berhenti sejenak, baru mengirim satu request berisi apa yang diketik.

## Fungsi debounce

```js
function debounce(func, delay) {
  let timeoutId
  return function (...args) {
    clearTimeout(timeoutId)
    timeoutId = setTimeout(() => func.apply(this, args), delay)
  }
}
```

Setiap panggilan menghapus timer dari panggilan sebelumnya dengan `clearTimeout()` lalu memulai timer baru. Jadi `func` hanya berjalan kalau tidak ada panggilan baru selama satu `delay` penuh.

Sekarang misalkan kita punya fungsi pencarian:

```js
async function searchAPI(query) {
  try {
    const response = await fetch(`/api/search?q=${query}`)
    const results = await response.json()
    displayResults(results)
  } catch (error) {
    console.error('Error:', error)
  }
}
```

Kalau dipasang tanpa debouncing, fungsi ini jalan di tiap ketikan:

```js
// tanpa debouncing — satu panggilan API per ketikan
document.getElementById('search').addEventListener('input', (e) => {
  searchAPI(e.target.value)
})

// "a" → panggil
// "app" → panggil
// "appl" → panggil
// "apple" → panggil
```

Bungkus handler-nya dengan `debounce()` dan ia menunggu jeda — satu panggilan, bukan empat:

```js
// dengan debouncing — satu panggilan API setelah user berhenti mengetik
document.getElementById('search').addEventListener(
  'input',
  debounce((e) => searchAPI(e.target.value), 300)
)

// "apple" → panggil
```

Bagi user perilakunya sama, tapi request-nya jauh lebih sedikit.
