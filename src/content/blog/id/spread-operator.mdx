Spread operator (`...`) mengekspansi sebuah iterable (array, string, atau objek) menjadi elemen-elemennya satu per satu. Fitur ini hadir sejak ES6 dan cepat jadi salah satu hal yang dipakai tiap hari: menggabungkan array, menyalin objek, atau mengoper daftar argumen, semuanya tanpa mengubah data aslinya.

## Array

```javascript
// Menggabungkan dua array
const buah = ['apel', 'pisang']
const sayuran = ['wortel', 'tomat']
const gabungan = [...buah, ...sayuran]
// ['apel', 'pisang', 'wortel', 'tomat']

// Menyalin array
const asli = [1, 2, 3]
const salinan = [...asli]
```

## Argumen fungsi

Ekspansi array menjadi argumen terpisah yang diminta sebuah fungsi:

```javascript
const angka = [1, 2, 3]
Math.max(...angka) // sama dengan Math.max(1, 2, 3)
```

## Objek

```javascript
const pengguna = { nama: 'Budi', umur: 30 }
const denganLokasi = { ...pengguna, lokasi: 'Jakarta' }
// { nama: 'Budi', umur: 30, lokasi: 'Jakarta' }
```

Urutan berpengaruh. Properti yang ditulis belakangan menimpa yang di depan, pas untuk menggabungkan nilai default dengan nilai override:

```javascript
const bawaan = { tema: 'terang', notifikasi: true }
const preferensi = { tema: 'gelap' }

const pengaturan = { ...bawaan, ...preferensi }
// { tema: 'gelap', notifikasi: true }
```

Balik urutannya, dan nilai default yang menang.

## Set dan Map

Karena keduanya iterable, spread mengubahnya kembali menjadi array, cara cepat untuk membuang duplikat:

```javascript
const unik = [...new Set([1, 2, 2, 3, 3, 4])]
// [1, 2, 3, 4]

const peta = new Map([['a', 1], ['b', 2]])
const entri = [...peta]
// [['a', 1], ['b', 2]]
```

## Spread vs rest

Tiga titik yang sama, tugas yang berlawanan. Spread membongkar koleksi menjadi item; rest mengumpulkan item kembali menjadi array. Cara membedakannya: rest muncul di daftar parameter fungsi, spread di tempat lainnya.

```javascript
// rest: mengumpulkan
function kumpulkan(...args) {
  return args
}
kumpulkan(1, 2, 3) // [1, 2, 3]

// spread: mengekspansi
const angka = [1, 2, 3]
console.log(...angka) // 1 2 3
```

## Jebakan shallow copy

Ini yang paling sering menjebak. Spread cuma menyalin satu level. Objek bersarang tetap dibagikan lewat referensi, jadi mengubahnya ikut mengubah data aslinya.

```javascript
const bersarang = { a: { b: 1 } }
const salinan = { ...bersarang }

salinan.a.b = 2
bersarang.a.b // 2 — data asli ikut berubah
```

Kalau butuh deep copy sungguhan, pakai `structuredClone`:

```javascript
const salinan = structuredClone(bersarang)
```

(`JSON.parse(JSON.stringify(...))` juga bisa, tapi membuang fungsi, objek `Date`, dan apa pun yang tak bisa direpresentasikan JSON.)

## Paling berguna: update yang immutable

Pembaruan state di React dan Redux mengandalkan pengembalian objek baru alih-alih mengubah yang lama. Spread membuatnya rapi:

```javascript
function reducer(state, action) {
  switch (action.type) {
    case 'UPDATE_USER':
      return {
        ...state,
        user: { ...state.user, ...action.payload },
      }
  }
}
```

## Beberapa catatan

- Untuk array yang sangat besar (ribuan elemen), `concat()` bisa lebih cepat daripada spread.
- Spread sudah didukung semua browser modern. Kalau harus mendukung Internet Explorer, transpile dengan Babel.

Segitu saja. Begitu menggabungkan, menyalin, dan menimpa jadi satu baris, susah kembali ke cara lama — cukup ingat perilaku shallow copy saat datamu bersarang.
