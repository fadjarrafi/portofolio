Operator ternary adalah bentuk singkat satu baris dari `if-else`. Ini satu-satunya operator JavaScript yang punya tiga bagian — sebuah kondisi, nilai saat kondisi benar, dan nilai saat kondisi salah.

```js
kondisi ? nilaiJikaBenar : nilaiJikaSalah
```

Bedanya dengan `if-else`, ternary adalah sebuah *ekspresi* — ia menghasilkan nilai yang bisa langsung kamu tetapkan:

```js
const keranjang = 'apel'

// if-else
let hasil
if (keranjang === 'apel') {
  hasil = 'Keranjang ini berisi apel'
} else {
  hasil = 'Keranjang ini tidak berisi apel'
}

// ternary — hal yang sama, satu baris
const hasil = keranjang === 'apel' ? 'Keranjang ini berisi apel' : 'Keranjang ini tidak berisi apel'
```

## Kapan berguna

Menetapkan nilai berdasarkan kondisi, atau mengembalikannya dari sebuah fungsi, adalah tempat terbaiknya. Ternary sangat umum di React untuk memilih komponen atau nama kelas:

```jsx
return <div>{isLoggedIn ? <UserDashboard /> : <LoginForm />}</div>

<button className={isActive ? 'btn-active' : 'btn-inactive'}>Klik saya</button>
```

Untuk sekadar nilai default, pakai `??` (nullish coalescing) saja — lebih jelas dan hanya jatuh ke default kalau nilainya `null` atau `undefined`:

```js
// jalan, tapi bertele-tele
const nama = user.name ? user.name : 'Tamu'

// lebih baik
const nama = user.name ?? 'Tamu'
```

## Jangan disarangkan

Kamu *bisa* merangkai ternary, tapi keterbacaannya langsung anjlok:

```js
const hasil =
  keranjang === 'apel'
    ? 'Keranjang ini berisi apel'
    : keranjang === 'pisang'
      ? 'Keranjang ini berisi pisang'
      : 'Keranjang ini tidak berisi buah'
```

Begitu ada lebih dari satu kondisi, `if-else` (atau `switch`) lebih mudah diikuti:

```js
if (keranjang === 'apel') {
  hasil = 'Keranjang ini berisi apel'
} else if (keranjang === 'pisang') {
  hasil = 'Keranjang ini berisi pisang'
} else {
  hasil = 'Keranjang ini tidak berisi buah'
}
```

## Beberapa jebakan

Jaga kedua cabang bertipe sama — mencampur string dengan `false` bikin masalah di kemudian hari:

```js
const hasil = isValid ? 'Valid' : false // hindari
const hasil = isValid ? 'Valid' : 'Tidak Valid' // lebih jelas
```

Dan pakai untuk nilai, bukan side effect. Kalau tiap cabang *melakukan* sesuatu, bukan *mengembalikan* sesuatu, gunakan `if-else`:

```js
// jangan
isLoggedIn ? simpanData() : tampilkanFormLogin()

// lakukan
if (isLoggedIn) {
  simpanData()
} else {
  tampilkanFormLogin()
}
```

Patokannya: ternary harusnya membuat satu baris lebih mudah dibaca sekilas. Begitu tidak, `if-else` yang lebih baik.
