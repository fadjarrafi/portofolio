Array ada di mana-mana, dan JavaScript menyediakan sekumpulan method untuk mengolahnya tanpa menulis loop secara manual. Yang paling sering dipakai adalah `map`, `filter`, `reduce`, `find`, `findIndex`, `push`, `pop`, `shift`, `unshift`, `slice`, `splice`, `forEach`, `some`, dan `every`. Mari kita bahas satu per satu.

Tiga yang paling sering dipakai adalah `map`, `filter`, dan `reduce` — mengubah tiap elemen, menyaring yang dibutuhkan, atau meringkas semuanya jadi satu nilai:

## map

`map()` menjalankan tiap elemen lewat sebuah fungsi dan mengembalikan array baru berisi hasilnya — panjangnya sama, nilainya berubah. Misalnya kita ingin mengalikan tiap angka dengan 2:

```javascript
const numbers = [1, 2, 3, 4]
const doubled = numbers.map((num) => num * 2)
// [2, 4, 6, 8]
```

`map()` juga andalan untuk mengambil satu field dari kumpulan objek:

```javascript
const users = [
  { id: 1, name: 'John' },
  { id: 2, name: 'Jane' },
  { id: 3, name: 'Doe' },
]
const userIds = users.map((user) => user.id)
// [1, 2, 3]
```

## filter

`filter()` mengembalikan array baru berisi elemen yang lolos sebuah tes. Callback mengembalikan `true` untuk menyimpan elemen, `false` untuk membuangnya:

```javascript
const ages = [15, 25, 35, 12, 40]
const adults = ages.filter((age) => age >= 18)
// [25, 35, 40]
```

Di sini kita hanya menyimpan umur yang 18 ke atas.

## reduce

`reduce()` meringkas array menjadi satu nilai. Ia menelusuri tiap elemen sambil membawa sebuah akumulator, dan kita yang menentukan bagaimana keduanya digabung:

```javascript
const prices = [10, 20, 30]
const total = prices.reduce((sum, price) => sum + price, 0)
// 60
```

Akumulator mulai dari `0`, lalu tiap harga ditambahkan ke atasnya sampai tersisa `60`.

## find dan findIndex

Keduanya mencari elemen pertama yang cocok dengan sebuah kondisi:

- `find()` mengembalikan elemennya.
- `findIndex()` mengembalikan posisinya di dalam array.

```javascript
const users = [
  { id: 1, name: 'John' },
  { id: 2, name: 'Jane' },
]

const john = users.find((user) => user.name === 'John')
const johnIndex = users.findIndex((user) => user.name === 'John')
```

## push, pop, shift, dan unshift

Method ini mengubah array asli dengan menambah atau menghapus satu elemen di salah satu ujungnya — dasar dari stack dan queue:

```javascript
const fruits = ['apple']

fruits.push('banana') // menambah di akhir: ['apple', 'banana']
fruits.pop() // menghapus dari akhir: ['apple']
fruits.unshift('orange') // menambah di depan: ['orange', 'apple']
fruits.shift() // menghapus dari depan: ['apple']
```

## slice dan splice

Namanya mirip, tugasnya beda — dan salah satunya mengubah array asli:

```javascript
// slice: menyalin sebagian, array aslinya tidak berubah
const numbers = [1, 2, 3, 4, 5]
const subset = numbers.slice(1, 3) // [2, 3]

// splice: mengubah array di tempat, menghapus/mengganti elemen
const letters = ['a', 'b', 'c']
letters.splice(1, 1, 'x') // mengganti 'b' dengan 'x' → ['a', 'x', 'c']
```

## forEach

`forEach()` menjalankan sebuah fungsi untuk tiap elemen tanpa membuat array baru. Cocok untuk side effect — mencatat log, atau memperbarui sesuatu di luar loop:

```javascript
const items = ['book', 'pen', 'desk']

items.forEach((item, index) => {
  console.log(`Item ${index + 1}: ${item}`)
})
```

## some dan every

Keduanya mengembalikan boolean setelah menguji elemen array:

- `some()` — apakah ada minimal satu elemen yang cocok?
- `every()` — apakah semua elemen cocok?

```javascript
const scores = [75, 80, 95]

const hasPassingScore = scores.some((score) => score >= 90) // true
const allPassed = scores.every((score) => score >= 70) // true
```

## Penutup

Sebagian besar pekerjaan dengan array intinya memilih method yang tepat: `map` untuk mengubah, `filter` untuk menyaring, `reduce` untuk menggabungkan, dan sisanya untuk tugas-tugas kecil di antaranya. Pakai method ini daripada loop manual, dan kodemu jadi lebih ringkas serta lebih mudah dibaca.
