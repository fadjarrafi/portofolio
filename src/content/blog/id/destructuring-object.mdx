Destructuring adalah cara singkat untuk mengeluarkan properti dari sebuah objek ke dalam variabel masing-masing. Daripada mengambil properti satu per satu, kita ambil semua yang dibutuhkan dalam satu baris.

Anggap kita punya objek `apple` dengan properti `name`, `color`, `weight`, dan `taste`:

```js
const apple = {
  name: 'Apple',
  color: 'Red',
  weight: 150,
  taste: 'Sweet',
}
```

Tanpa destructuring, kita harus menetapkan tiap properti di barisnya sendiri:

```js
const name = apple.name // 'Apple'
const color = apple.color // 'Red'
const weight = apple.weight // 150
const taste = apple.taste // 'Sweet'
```

Cara ini cepat terasa merepotkan, apalagi kalau objeknya besar atau bertingkat seperti respons JSON dari sebuah API.

## Dasarnya

Ini hal yang sama dengan destructuring — cukup satu baris:

```js
const { name, color, weight } = apple

console.log(name) // 'Apple'
console.log(color) // 'Red'
```

Tiap variabel mengambil nilai dari properti yang namanya cocok di `apple`.

## Beberapa pola yang berguna

### Mengganti nama variabel

Beri nama lain pada variabel dengan tanda titik dua:

```js
const { name: fruitName, color: fruitColor } = apple

console.log(fruitName) // 'Apple'
console.log(fruitColor) // 'Red'
```

### Nilai default

Kalau propertinya tidak ada, variabelnya jadi `undefined`. Kita bisa menyiapkan nilai cadangan:

```js
const { size = 'Medium' } = apple

console.log(size) // 'Medium'
```

Karena `apple` tidak punya properti `size`, nilai default-nya yang dipakai.

### Nested object

Kita juga bisa masuk ke objek bertingkat — berguna untuk respons API:

```js
const fruit = {
  name: 'Apple',
  nutrients: {
    vitamin_c: 4.6,
    fiber: 2.4,
  },
}

const {
  nutrients: { vitamin_c, fiber },
} = fruit

console.log(vitamin_c) // 4.6
console.log(fiber) // 2.4
```

### Parameter fungsi

Destructuring bisa langsung dipakai di daftar parameter, jadi fungsi cukup mengambil field yang dibutuhkan saja:

```js
function describeFruit({ name, color, taste }) {
  return `The ${name} is ${color} and tastes ${taste}.`
}

describeFruit(apple) // 'The Apple is Red and tastes Sweet.'
```

Segini dulu yang paling sering dipakai sehari-hari. Begitu terbiasa, destructuring bakal kamu pakai di mana-mana — respons API, argumen fungsi, sampai import.
