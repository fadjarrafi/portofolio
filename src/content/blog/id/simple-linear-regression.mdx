Bagaimana sebuah perusahaan memutuskan berapa besar biaya iklannya, atau seorang agen menentukan harga rumah? Sering kali alat di balik keputusan itu adalah regresi linier sederhana: cara untuk menggambarkan dan memprediksi hubungan antara dua variabel. Bayangkan seperti mencari benang merah yang menghubungkan biaya iklan ($x$) dengan penjualan ($y$).

Secara matematis, hubungan itu terlihat seperti ini:

$$ 
y = \beta_0 + \beta_1 x + \varepsilon
$$

Di mana: 

| Simbol        | Pengertian    |
| ------------- | ------------- |
| $x$             | Variabel independen |
| $y$             | Variabel dependen|
| β₀            | *Intercept* (nilai $y$ ketika $x$ = 0)|
| β₁            | *Slope* (seberapa besar perubahan $y$ untuk setiap unit perubahan $x$)|
| ε             | *Error term*|

## Fungsi Regresi Linier

Regresi linier melakukan dua hal:

1. **Membuktikan hubungan**: membuktikan secara statistik apakah dua variabel benar-benar berhubungan, dan mengukur seberapa kuat hubungan itu. *Apakah tingkat pendidikan benar-benar memengaruhi pendapatan?*
2. **Memprediksi**: memperkirakan nilai di masa depan dari data lampau. *Jika anggaran iklan dinaikkan sebesar $x$, berapa tambahan penjualan ($y$) yang bisa diharapkan?*

## Menghitung Regresi Linier

Misalkan kita ingin tahu hubungan antara biaya iklan ($x$) dan penjualan ($y$), dengan data berikut:

| Biaya Iklan  | Unit          |
| ------------ | ------------- |
| 100          | 500           |
| 200          | 700           |
| 300          | 900           |
| 400          | 1100          |
| 500          | 1300          |

Untuk menyusun garisnya, kita butuh dua angka: slope $\beta_1$ dan intercept $\beta_0$.

### Menghitung *Slope* ($\beta_1$)

*Slope* atau kemiringan adalah seberapa besar $y$ bergerak untuk setiap perubahan $x$:

$$
\beta_1 = \frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sum(x_i - \bar{x})^2}
$$

Di mana: 

| Simbol            | Pengertian    |
| ----------------- | ------------- |
| $x_i$             | Nilai individual variabel independen |
| $y_i$             | Nilai individual variabel dependen |
| $\bar{x}$         | Rata-rata variabel independen |
| $\bar{y}$         | Rata-rata variabel dependen |

Mulai dari kedua rata-rata:

$$ \bar{x} = (100 + 200 + 300 + 400 + 500) / 5 = 300 $$
$$ \bar{y} = (500 + 700 + 900 + 1100 + 1300) / 5 = 900 $$

Sekarang pembilangnya, tiap $(x_i - \bar{x})(y_i - \bar{y})$:

$$ (100 - 300)(500 - 900) = (-200)(-400) = 80,000 $$
$$ (200 - 300)(700 - 900) = (-100)(-200) = 20,000 $$
$$ (300 - 300)(900 - 900) = (0)(0) = 0 $$
$$ (400 - 300)(1100 - 900) = (100)(200) = 20,000 $$
$$ (500 - 300)(1300 - 900) = (200)(400) = 80,000 $$

$$ \text{Total} = 200,000 $$

Lalu penyebutnya, tiap $(x_i - \bar{x})^2$:

$$ (100 - 300)^2 = (-200)^2 = 40,000 $$
$$ (200 - 300)^2 = (-100)^2 = 10,000 $$
$$ (300 - 300)^2 = (0)^2 = 0 $$
$$ (400 - 300)^2 = (100)^2 = 10,000 $$
$$ (500 - 300)^2 = (200)^2 = 40,000 $$

$$ \text{Total} = 100,000 $$
$$ \beta_1 = 200,000 / 100,000 = 2 $$

*Slope* bernilai 2 berarti setiap tambahan 1 unit biaya ($x$) membawa 2 unit penjualan tambahan ($y$).

### Menghitung *Intercept* ($\beta_0$)

Dengan *slope* di tangan, *intercept*-nya adalah:

$$
\beta_0 = \bar{y} - \beta_1\bar{x}
$$

Di mana:

| Simbol            | Pengertian    |
| ----------------- | ------------- |
| $\bar{y}$         | Rata-rata variabel dependen |
| $\bar{x}$         | Rata-rata variabel independen |
| $\beta_1$         | *Slope* |

$$ \beta_0 = 900 - (2 × 300) $$
$$ \beta_0 = 300 $$

Jadi ketika biaya iklan 0, prediksi penjualan adalah 300 unit. Gabungkan *slope* dan *intercept*, dan kita dapat garis regresinya:

$$ y = 300 + 2x $$

Untuk memprediksi, tinggal masukkan nilainya. Berapa penjualan dari biaya iklan 250?

$$ y = 300 + 2(250) = 300 + 500 = 800 $$

Jadi biaya iklan 250 memprediksi 800 unit. Digambar, garis dan kelima titik datanya seperti ini:

Berikut perhitungan yang sama dalam bentuk program:

```js
// Data penjualan dan iklan
const data_penjualan = {
    biaya_iklan: [100, 200, 300, 400, 500],
    unit_terjual: [500, 700, 900, 1100, 1300]
};

// Menghitung rata-rata dari array
function hitung_rata_rata(data) {
    return data.reduce((total, nilai) => total + nilai, 0) / data.length;
}

// Menghitung slope (β₁) dari data
function hitung_slope(data) {
    const rata_x = hitung_rata_rata(data.biaya_iklan);
    const rata_y = hitung_rata_rata(data.unit_terjual);
    
    let pembilang = 0;
    let penyebut = 0;
    
    // Hitung pembilang dan penyebut untuk rumus slope
    for (let i = 0; i < data.biaya_iklan.length; i++) {
        const selisih_x = data.biaya_iklan[i] - rata_x;
        const selisih_y = data.unit_terjual[i] - rata_y;
        
        pembilang += selisih_x * selisih_y;
        penyebut += selisih_x * selisih_x;
    }
    
    return pembilang / penyebut;
}

// Menghitung intercept (β₀) dari data
function hitung_intercept(data, slope) {
    const rata_x = hitung_rata_rata(data.biaya_iklan);
    const rata_y = hitung_rata_rata(data.unit_terjual);
    
    return rata_y - (slope * rata_x);
}

// Memprediksi unit terjual berdasarkan biaya iklan
function prediksi_penjualan(biaya_iklan, slope, intercept) {
    return intercept + (slope * biaya_iklan);
}

// Hitung regresi
const slope = hitung_slope(data_penjualan);
const intercept = hitung_intercept(data_penjualan, slope);

// Tampilkan hasil
console.log(`Slope (β₁): ${slope}`); // output: 2
console.log(`Intercept (β₀): ${intercept}`); // output: 300

// Contoh prediksi
const biaya_baru = 250;
const prediksi = prediksi_penjualan(biaya_baru, slope, intercept);
console.log(`${prediksi} unit`);
```

## Asumsi Klasik Regresi Linier

Regresi hanya andal jika beberapa asumsi terpenuhi. Ada baiknya diperiksa sebelum kamu mempercayai hasilnya:

1. **Linearitas.** Hubungan antara $x$ dan $y$ harus kira-kira berupa garis lurus. Scatter plot adalah cara cepat memeriksanya. Jika titik-titiknya justru melengkung, transformasi data dulu (logaritma atau akar kuadrat biasanya membantu).
2. **Independensi.** Setiap pengamatan harus berdiri sendiri. Ini paling terasa pada data time series: penjualan hari ini seharusnya tidak dipengaruhi penjualan kemarin. Autokorelasi (diperiksa dengan plot ACF atau uji Durbin-Watson) membuat hasilnya bias.
3. **Homoskedastisitas.** Sebaran error harus tetap konstan di semua nilai $x$ — kesalahan prediksi tidak boleh kecil untuk biaya iklan rendah lalu besar untuk yang tinggi. Plot residual terhadap nilai prediksi; bentuk corong menandakan asumsi ini tidak terpenuhi.
4. **Normalitas.** Residual harus mengikuti distribusi normal: berbentuk lonceng simetris saat dibuat histogram. Ini penting terutama untuk uji hipotesis dan interval kepercayaan. Periksa dengan Q-Q plot, atau uji formal seperti Shapiro-Wilk.

## Menguji Kecocokan dengan R²

Seberapa baik garisnya benar-benar menjelaskan data? Itulah yang diukur koefisien determinasi, $R^2$:

$$ R^2 = 1 - \frac{\sum(y_i - \hat{y_i})^2}{\sum(y_i - \bar{y})^2} $$

Di mana: 

| Simbol            | Pengertian    |
| ----------------- | ------------- |
| $y_i$             | Nilai aktual |
| $\hat{y_i}$       | Nilai prediksi |
| $\bar{y}$         | Rata-rata nilai aktual |

$R^2$ berkisar dari 0 sampai 1 dan menunjukkan porsi keragaman $y$ yang berhasil ditangkap model. Kalikan 100 untuk membacanya sebagai persentase. Untuk menghitungnya, kita perlu nilai prediksi, total sum of squares, dan residual sum of squares.

### Nilai Prediksi ($\hat{y_i}$)

Jalankan tiap $x$ melalui $y = 300 + 2x$:

| Biaya Iklan ($x$)  | Unit ($y$)      | $\hat{y}$ (prediksi) |
| ---------------- | ------------- | ---------------------- |
| 100              | 500           | 300 + 2(100) = 500     | 
| 200              | 700           | 300 + 2(200) = 700     |
| 300              | 900           | 300 + 2(300) = 900     |
| 400              | 1100          | 300 + 2(400) = 1100    |
| 500              | 1300          | 300 + 2(500) = 1300    |

### Total Sum of Squares ($SS_{total}$)

Ini sebaran nilai aktual terhadap rata-ratanya, $\sum(y_i - \bar{y})^2$:

$$ (500 - 900)^2 = (-400)^2 = 160,000 $$
$$ (700 - 900)^2 = (-200)^2 = 40,000 $$
$$ (900 - 900)^2 = 0 $$
$$ (1100 - 900)^2 = (200)^2 = 40,000 $$
$$ (1300 - 900)^2 = (400)^2 = 160,000 $$
$$ SS_{total} = 400,000 $$

### Residual Sum of Squares ($SS_{residual}$)

Ini yang tidak tertangkap model (selisih antara aktual dan prediksi, $\sum(y_i - \hat{y_i})^2$):

$$ (500 - 500)^2 = 0 $$
$$ (700 - 700)^2 = 0 $$
$$ (900 - 900)^2 = 0 $$
$$ (1100 - 1100)^2 = 0 $$
$$ (1300 - 1300)^2 = 0 $$
$$ SS_{residual} = 0 $$

### Menyatukannya

$$ R^2 = 1 - \frac{SS_{residual}}{SS_{total}} = 1 - \frac{0}{400,000} = 1 $$

$R^2$ bernilai 1 berarti:

1. model menjelaskan 100% keragaman dalam data,
2. setiap titik berada tepat di garis, dan
3. prediksi sempurna untuk data ini.

Itu terjadi di sini karena datanya benar-benar linier — semua residual bernilai nol. Data di dunia nyata hampir tidak pernah sebersih ini. Berikut perhitungannya dalam kode:

```js
// Menghitung koefisien determinasi (R²)
function hitung_r_squared(data, slope, intercept) {
    const rata_y = hitung_rata_rata(data.unit_terjual);
    
    let ss_total = 0;  // Sum of squares total
    let ss_residual = 0;  // Sum of squares residual
    
    for (let i = 0; i < data.biaya_iklan.length; i++) {
        const y_prediksi = intercept + (slope * data.biaya_iklan[i]);
        const y_aktual = data.unit_terjual[i];
        
        ss_total += Math.pow(y_aktual - rata_y, 2);
        ss_residual += Math.pow(y_aktual - y_prediksi, 2);
    }
    
    return 1 - (ss_residual / ss_total);
}

// Penggunaan
const r_squared = hitung_r_squared(data_penjualan, slope, intercept);
console.log(`R² (Koefisien Determinasi): ${r_squared.toFixed(4)}`); // Output: 1.0000
```
