Kita sudah membahas [destructuring pada objek](/writing/id/destructuring-object). Array bekerja dengan cara yang sama, bedanya nilainya dicocokkan berdasarkan **posisi**, bukan nama.

## Dasarnya

```js
const fruits = ['apple', 'banana', 'grape', 'orange']

const [first, second, third, fourth] = fruits

console.log(first) // 'apple'
console.log(second) // 'banana'
```

Variabel pertama mengambil elemen pertama, variabel kedua mengambil elemen kedua, begitu seterusnya.

## Beberapa pola yang berguna

### Melewati elemen

Beri jarak dengan koma untuk melewati elemen yang tidak dibutuhkan:

```js
const fruits = ['apple', 'banana', 'grape', 'orange']
const [first, , third] = fruits

console.log(first) // 'apple'
console.log(third) // 'grape'
```

### Rest

Kumpulkan sisa elemen ke dalam array dengan `...`:

```js
const fruits = ['apple', 'banana', 'grape', 'orange']
const [first, second, ...remaining] = fruits

console.log(first) // 'apple'
console.log(remaining) // ['grape', 'orange']
```

### Nilai default

Siapkan nilai cadangan untuk elemen yang mungkin tidak ada:

```js
const colors = ['red']
const [primary, secondary = 'blue'] = colors

console.log(primary) // 'red'
console.log(secondary) // 'blue' — nilai default
```

### Array bersarang

Kita bisa masuk ke array bersarang dengan meniru bentuknya:

```js
const fruits = ['apple', ['red', 'green'], 'banana']
const [name, [color1, color2]] = fruits

console.log(name) // 'apple'
console.log(color1) // 'red'
console.log(color2) // 'green'
```

### Digabung dengan objek

Destructuring array dan objek bisa dipadukan saat datanya campuran:

```js
const data = ['apple', { color: 'red', weight: 150 }]
const [name, { color, weight }] = data

console.log(name) // 'apple'
console.log(color) // 'red'
console.log(weight) // 150
```

### Parameter fungsi

Destructuring bisa langsung di daftar parameter:

```js
function analyzeFruits([first, second, ...others]) {
  console.log(`Pertama: ${first}`)
  console.log(`Kedua: ${second}`)
  console.log(`Lainnya: ${others.join(', ')}`)
}

analyzeFruits(['apple', 'banana', 'grape', 'orange'])
```

### Menukar nilai

Trik yang rapi — menukar dua variabel tanpa variabel bantu:

```js
let a = 'apple'
let b = 'banana'

;[a, b] = [b, a]

console.log(a) // 'banana'
console.log(b) // 'apple'
```

### Iterable lain

Tidak terbatas pada array. String dan set juga bisa, karena keduanya iterable:

```js
const [x, y, z] = 'xyz'
console.log(x, y, z) // 'x' 'y' 'z'

const [head, ...rest] = new Set([1, 2, 3])
console.log(head, rest) // 1 [2, 3]
```

## Di mana kamu akan menemuinya

Dua contoh sehari-hari: memecah string, dan `useState` di React yang mengembalikan pasangan `[value, setter]` yang namanya kamu tentukan sendiri.

```js
const [year, month, day] = '2024-09-29'.split('-')

const [count, setCount] = useState(0)
```

Begitu destructuring berbasis posisi ini terbiasa, kamu bakal melihatnya di mana-mana — nilai kembalian fungsi, hooks, dan di mana pun sebuah fungsi mengembalikan lebih dari satu nilai.
