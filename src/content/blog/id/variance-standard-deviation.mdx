Varians mengukur seberapa tersebar sekumpulan angka dari nilai rata-ratanya (mean). Bayangkan varians sebagai jarak rata-rata antara tiap titik data dan pusatnya — hanya saja jarak itu dikuadratkan, dan hal itu ternyata cukup berpengaruh.

Misalkan kamu mengukur tinggi pohon di dua hutan. Di Hutan A sebagian besar pohon setinggi sekitar 30 meter, kurang lebih seragam. Di Hutan B tingginya beragam, mulai dari 10 meter hingga 50. Rata-rata tinggi pohon di kedua hutan sama-sama 30 meter, tapi sebarannya jelas berbeda — dan perbedaan itulah yang ditangkap oleh varians.

## Definisi Rumus

Berikut rumusnya, tahap demi tahap:

1. Cari nilai rata-rata (μ) dari data.
2. Untuk tiap nilai, kurangkan rata-ratanya (jaraknya dari pusat) lalu kuadratkan hasilnya (untuk menghilangkan tanda dan memberi bobot lebih pada selisih yang besar).
3. Hitung rata-rata dari semua selisih yang sudah dikuadratkan.

$$
\sigma^2 = \frac{\sum (x - \mu)^2}{N}
$$

Di mana:

| Simbol  | Pengertian |
|---------|------------|
| $\sigma^2$ | Varians |
| $x$ | Setiap nilai dalam kumpulan data |
| $\mu$ | Rata-rata dari kumpulan data, dihitung sebagai $\mu = \frac{\sum x}{N}$ |
| $N$ | Jumlah total nilai dalam kumpulan data |
| $\sum$ | Notasi sigma, berarti "jumlahkan semua yang mengikuti" |

## Implementasi dalam Pemrograman

Berikut matematika yang sama dalam JavaScript:

```javascript
// Fungsi untuk menghitung rata-rata dari sebuah array
const calculateMean = (numbers) => {
    return numbers.reduce((sum, num) => sum + num, 0) / numbers.length;
};

// Fungsi utama untuk menghitung varians
const calculateVariance = (numbers) => {
    const mean = calculateMean(numbers);
    const squaredDifferences = numbers.map(num => Math.pow(num - mean, 2));
    return calculateMean(squaredDifferences);
};

// Fungsi untuk menghitung standar deviasi
const calculateStandardDeviation = (numbers) => {
    return Math.sqrt(calculateVariance(numbers));
};

// Contoh penggunaan
const exploreVariance = (datasetName, numbers) => {
    console.log(`\nAnalisis ${datasetName}:`);
    console.log(`Data: [${numbers.join(', ')}]`);
    console.log(`Mean: ${calculateMean(numbers).toFixed(2)}`);
    console.log(`Varians: ${calculateVariance(numbers).toFixed(2)}`);
    console.log(`Standar Deviasi: ${calculateStandardDeviation(numbers).toFixed(2)}`);
};

// Contoh kumpulan data dengan varians berbeda
const hutanA = [28, 29, 30, 31, 32];
const hutanB = [10, 20, 30, 40, 50];

exploreVariance('Hutan A (Tinggi Seragam)', hutanA);
exploreVariance('Hutan B (Tinggi Bervariasi)', hutanB);
// Output akan menunjukkan bahwa Hutan B punya varians lebih besar dari Hutan A
```

## Mengapa Harus Dikuadratkan?

Mengkuadratkan selisih melakukan tiga hal yang berguna:

1. **Mengatasi nilai negatif.** Selisih bisa positif atau negatif; dengan dikuadratkan semuanya jadi positif sehingga tidak saling meniadakan.
2. **Menekankan outlier.** Nilai yang jauh dari rata-rata menghasilkan selisih kuadrat yang besar, jadi varians bereaksi kuat terhadap titik-titik yang jauh melenceng.
3. **Menjaga matematikanya tetap mulus.** Kuadrat menghasilkan fungsi yang dapat diturunkan, yang berguna untuk berbagai persoalan optimasi yang dibangun di atas varians.

## Interpretasi Varians dan Standar Deviasi

Keduanya bukan sekadar angka abstrak: keduanya memberi tahu bentuk sebaran datamu.

1. **Varians dan standar deviasi kecil.** Nilai-nilai berkumpul rapat di sekitar rata-rata. Dalam produksi suku cadang mobil, standar deviasi kecil berarti ukuran suku cadang yang dihasilkan konsisten.
2. **Varians dan standar deviasi besar.** Nilai tersebar jauh dari rata-rata, menandakan variabilitas tinggi. Dalam investasi saham, standar deviasi besar berarti volatilitas tinggi: harga bisa berayun jauh.
3. **Perbandingan antar dataset.** Dua dataset bisa punya **rata-rata sama tetapi varians berbeda**. Jika dua sekolah punya rata-rata nilai ujian sama tetapi satu punya standar deviasi lebih tinggi, hasil di sekolah itu lebih timpang.
4. **Kaitan dengan distribusi normal.** Dalam distribusi normal, **sekitar 68% data berada dalam satu standar deviasi dari rata-rata**, **95% dalam dua**, dan **99,7% dalam tiga**, cara cepat untuk mengenali outlier.

## Jenis-jenis Varians

Ada dua, tergantung apakah kamu memiliki seluruh populasi atau hanya sampel darinya:

1. **Varians Populasi (σ²)**: dipakai saat kamu memiliki **seluruh nilai dalam populasi**.

    $$\sigma^2 = \frac{\sum (x - \mu)^2}{N}$$

    Misalnya, data berat badan **seluruh** penduduk suatu kota.

2. **Varians Sampel (s²)**: dipakai saat kamu hanya memiliki **sebagian populasi** (sampel).

    $$s^2 = \frac{\sum (x - \bar{x})^2}{n - 1}$$

    Bedanya adalah membagi dengan **(n − 1) alih-alih N**. Ini koreksi **derajat kebebasan (degrees of freedom)**, yang menjaga estimasi agar tidak bias terlalu rendah. Misalnya, data berat badan dari hanya **100 orang** di kota, bukan semuanya.

## Kapan Menggunakan Varians Populasi vs. Sampel?

- Gunakan **varians populasi** saat kamu punya **seluruh data** dari kelompok yang dianalisis.
- Gunakan **varians sampel** saat kamu hanya punya **sebagian data** dan ingin mengestimasi varians seluruh populasi.

## Hubungan dengan Standar Deviasi

Standar deviasi (σ) adalah akar kuadrat dari varians. Varians praktis untuk perhitungan, tapi standar deviasi lebih mudah dibaca karena kembali ke satuan yang sama dengan data aslinya.
