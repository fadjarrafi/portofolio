# Known Issues

Re-audited against the current **Astro 5** codebase. The previous list documented the pre-migration Next.js version; those issues are resolved or no longer apply (see [Resolved](#resolved-post-migration) at the bottom). Line numbers below were current at the time of the audit.

## Notable

### 1. Hardcoded `lang="en"` on `<html>` — `src/layouts/BaseLayout.astro:34`
Every page — including Indonesian posts at `/writing/id/...` and `/garden/thoughts/id/...` — renders with `lang="en"` on the root element. Bad for accessibility (screen readers) and SEO.
**Fix:** Pass the post/page language into `BaseLayout` and set `lang` dynamically.

### 2. Missing OG fallback image — `public/og-default.png`
`BaseLayout.astro:28` and the three post pages fall back to `${siteUrl}/og-default.png` for the Open Graph / Twitter image, but no `og-default.png` exists in `public/`. Any page without an explicit `image` in frontmatter serves a 404 image URL, so social shares get no preview thumbnail.
**Fix:** Add `public/og-default.png`, or generate per-post OG images and set `image` in frontmatter.

## Minor

### 3. Nine Indonesian blog posts missing `summary`
All English posts now have a `summary`; these Indonesian posts do not, so their meta description falls back to the generic default (see #4) and JSON-LD `description` is empty:
`activation-function-in-deep-learning`, `array-method`, `cors-what-it-is`, `debouncing`, `destructuring-array`, `destructuring-object`, `es-module`, `spread-operator`, `ternary-operator`.
(RSS is unaffected — the feed is English-only.)
**Fix:** Add a `summary:` field to each file's frontmatter.

### 4. Generic default meta description — `src/layouts/BaseLayout.astro:19`
The `description` prop defaults to `'This is my portfolio.'`, which is what any page without its own description ships to search engines and social cards.
**Fix:** Set a real site-level description.

## Resolved (post-migration)

The Next.js → Astro migration cleared the earlier issues:

- **`site` / base URL** — now set to `https://fadjarrafi.my.id` in `astro.config.mjs` (note the domain changed from the previously-planned `.xyz`).
- **Sitemap & RSS URL structure** — RSS (`src/pages/rss.xml.ts`) links to `/writing/en/${slug}`; the sitemap is generated by `@astrojs/sitemap` at `/sitemap-index.xml`, covering all routes.
- **English post summaries** — every English blog post now has a `summary` (Indonesian gaps tracked in #3).
- **`server-only` import** — N/A in Astro; content is read in build-time frontmatter, not shared client/server utils.
- **Analytics** — replaced by Google Analytics 4, injected in `BaseLayout.astro` only when `PUBLIC_GA_ID` is set.
- **OG image default title & JSON-LD author** — title now derives from the page title; JSON-LD author is `Fadjar Rafi` (see the OG *image* gap in #2, which is a separate, still-open issue).
- **`pnpm-workspace.yaml`** — now tracked in git.
